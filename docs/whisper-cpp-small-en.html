Offline usage

Once whisper-cli, this model file, and any required local dependencies are already present, transcription does not need to download model weights from an external network.

whisper-cli -m ggml-small.en.bin -f audio.wav
This repository distributes the model file, not the whisper-cli executable. Obtain/build a compatible whisper.cpp runtime separately before going offline.

Verification and provenance

The workflow first verifies the OpenAI small.en.pt SHA-256 fingerprint from the official OpenAI Whisper model URL. Only that verified checkpoint is eligible for conversion. The generated ggml-small.en.manifest.json records the source checkpoint hash, output hash, exact OpenAI Whisper commit, exact whisper.cpp commit, converter path, byte size, and conversion time.

GitHub Actions artifact transport

Every successful manual model workflow run also creates a GitHub Actions artifact named openai-whisper-small-en-ggml-<model-sha-prefix>. It contains the GGML model, checksum, and provenance manifest and is retained for 90 days. This gives GitHub API and connector clients a binary-download route when direct release assets are unavailable in their execution environment.

When to use this file

Use ggml-small.en.bin when the target runtime is official whisper.cpp / whisper-cli. If the target runtime is Python OpenAI Whisper, use the PyTorch model ZIP instead.
