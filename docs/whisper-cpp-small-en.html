WHISPER-CPP-SMALL-EN(7)

NAME

ggml-small.en.bin — Whisper small.en for whisper.cpp.

SYNOPSIS

whisper-cli -m ggml-small.en.bin -f audio.wav

FILES

ggml-small.en.bin
ggml-small.en.bin.sha256
ggml-small.en.manifest.json

DESCRIPTION

The workflow verifies OpenAI's small.en.pt, converts it with the official whisper.cpp converter, and records the source hash and converter commit.

ACTIONS ARTIFACT

openai-whisper-small-en-ggml-<model-sha-prefix>

Use the latest successful manual workflow run when direct binary release downloads are unavailable.
