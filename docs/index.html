Use it for offline transcription

The archive supplies the model weights. Your machine still needs a compatible Whisper runtime and dependencies available locally before network access is removed.

1. Download and extract the archive while online

curl -L \
  -o openai-whisper-small-en-offline-model.zip \
  https://github.com/jwedwards-usa/ai-models/releases/latest/download/openai-whisper-small-en-offline-model.zip

mkdir -p whisper-small-en
unzip openai-whisper-small-en-offline-model.zip -d whisper-small-en

2. Load the local checkpoint with Whisper

import whisper

model = whisper.load_model("small.en", download_root="./whisper-small-en")
result = model.transcribe("audio.mp3", language="en")
print(result["text"])
Offline requirement: Python, a compatible Whisper package, PyTorch, FFmpeg, and any other runtime dependencies must already be installed or cached locally. The ZIP does not bundle a standalone transcription executable.

Frequently asked questions

Can Whisper small.en really run without internet access?

Yes, after both the model weights and a compatible runtime are available locally. This archive prevents the runtime from needing to download the small.en model weights at transcription time.

Is this a standalone Whisper executable?

No. It is a ZIP containing the small.en.pt model checkpoint and verification metadata. A Whisper-compatible runtime is still required.

How does the repository know whether a newer model exists?

The updater resolves the official small.en model URL from a pinned commit of OpenAI's Whisper repository and reads the SHA-256 fingerprint embedded in that URL. It downloads only when that fingerprint has not already been published here.

Is the model modified?

No. The workflow verifies the upstream checkpoint and places it into a ZIP alongside source and integrity metadata.
