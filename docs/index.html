AI-MODELS(7)

NAME

ai-models — Whisper small.en files for local transcription.

SYNOPSIS

unzip ggml-small.en.zip
whisper-cli -m ggml-small.en.bin -f audio.wav

FILES

ggml-small.en.zip
Preferred download. Contains ggml-small.en.bin, its checksum, and provenance manifest.
ggml-small.en.zip.sha256
ZIP checksum.
ggml-small.en.bin
Raw whisper.cpp model.
ggml-small.en.bin.sha256
Model checksum.
ggml-small.en.manifest.json
Source and converter provenance.
openai-whisper-small-en-offline-model.zip
Verified small.en.pt package.
model.json
Machine-readable metadata.

CHATGPT PROMPT

Plain-text prompt

Transcribe my uploaded audio entirely inside ChatGPT's Linux VM. Do not send the audio to an external ASR service.

Use official whisper.cpp with small.en. Download and extract:
https://github.com/jwedwards-usa/ai-models/releases/latest/download/ggml-small.en.zip

If that download is blocked, use the GitHub connector to get the latest successful "Update Whisper small.en" Actions artifact named openai-whisper-small-en-ggml-* from jwedwards-usa/ai-models and extract ggml-small.en.bin.

Also get the latest official ggml-org/whisper.cpp Linux x64 Actions artifact containing whisper-cli. Run locally with beam search, continuous context, and a domain-vocabulary prompt.

Return a validated .vtt. Fix only obvious ASR errors. Provide the sandbox download link.

UPDATE

Run Actions → Update Whisper small.en → Run workflow.

The workflow verifies the OpenAI checkpoint, converts it when needed, publishes the raw GGML file and ZIP, and refreshes the Actions artifact. Unchanged models are reused.

NOTES

This repository contains model data, not whisper-cli, Python, PyTorch, or FFmpeg.
